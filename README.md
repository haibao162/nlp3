1、清洗sql文件数据，使用正则表达式提取数据库表结构，按照表名、字段名和字段注释的格式写入db.json文件中，表的数量有400+。

2、读取db.json文件，将一个表的表名、字段名和注释拼接起来作为一句话用于相似度匹配和RAG提示词，一共400+个句子，每个句子不超过512个token，使用text2vec-base-chinese模型进行embedding，将向量存入本地。

3、人工标注表和表的关联字段，以无向邻接表的结构存储，用于sql语句中的多表关联查询，在最后送入大模型时将关联表追加到主表信息中。

4、 使用BM25算法先进行粗排：使用jieba分词将用户问题和处理好的400+个表的句子进行分词，过滤掉逗号、句号等标点符号，然后使用BM25算法计算它们的相似度得分，得到最相似的20个句子。

5、使用text2vec-base-chinese进行精排：将用户问题进行embedding，分别和embedding预处理过的表的句子计算余弦相似度，和BM25算法按照1比1的得分权重，从20个句子里得到5个得分最高的句子。

6、从人工标注的表关联关系中，查询5个得分最高的表有哪些关联的表，作为大模型提示词，句子总长度不超过5万。

7、使用Qwen-plus大模型，根据用户问题和筛选出来的数据库表信息，生成sql语句。
